The Rust adapter calls only ioctl_read_msr for a fixed read-register allowlist.
It provides no arbitrary module/function/IOCTL interface and never calls the
module's ioctl_write_msr. Driver install/start/stop is not implemented.

The copied binary provenance is the fixed RAMSPD snapshot; no binary was
rebuilt or resigned. Native reads allow only DDR5 identity, capability/enabled,
page and temperature registers under the standard global SMBus mutex. An
explicitly enabled sensor request may temporarily clear MR11 page bits 0..2
and must restore the complete original byte with independent readback.
No EEPROM/PMIC, addressing-mode, thermal-enable, threshold or write-protection
modification is exposed.
